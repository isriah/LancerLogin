Release boundaries

  • One self-hosted kiosk per installation; multi-kiosk synchronization is not included.
  • No migration or connection to any earlier attendance installation.
  • No PDF or Google Sheets export; CSV and documented D1 backup/restore are supported.
  • Captive portals are manual/offline-first and advanced compatibility is documented but unsupported.
