Open operations guidance
Community support is best-effort.Questions and responsible reports can be sent to robolancers@gmail.com. There is no response-time or uptime SLA.

Release boundaries

  • One self-hosted physical kiosk is supported per installation. The browser simulator is not a physical kiosk.
  • Web updates and physical-kiosk updates are separate procedures.
  • CSV and documented D1 backup/restore are supported; PDF and spreadsheet exports are not included.
  • Public documentation never contains credentials, private repository details, attendance records, or backup contents.
