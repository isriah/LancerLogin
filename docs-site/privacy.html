Plain-language notice

Privacy boundaries

Stored by your installation

  • Organization configuration, users, roster, meetings, attendance, corrections, and audit records in your D1 database
  • Encrypted integration credentials in D1; saved values are never displayed
  • Sensor slot-to-member mapping, queued events, and pairing material locally on the Pi
  • Fingerprint templates exclusively inside the R503 sensor

Never sent as telemetry

  • Organization name
  • Roster or personal names
  • Attendance records
  • Fingerprint templates or raw scans
  • Raw IP address

Consent-gated telemetry

Only after the first Admin clearly accepts, LancerLogin may send a random installation ID, release version, active kiosk count, scrubbed error category, and best-effort city/metro derived from the connection. Raw IP is not read into the payload or stored. An Admin can later decline in Privacy settings, which clears the telemetry installation ID.

Data remains in the adopter-owned installation until an Admin exports or deletes it. LancerLogin provides no migration path from earlier installations.
