LancerLogin releases

Review user-visible changes and migration notes before manually authorizing an upgrade in your private deployment repository.

v0.6.0

Recurring meetings and dashboard refinement

Create bounded daily, weekly, biweekly, or monthly meeting series, then search and edit every meeting attribute from one complete table.

  • Recurring schedules retain the selected organization-local time through daylight-saving changes.
  • Roster CSV preview with explicit add/update or replace confirmation before any data changes.
  • Temporary guided setup, persistent dark-first browser theme, clearer headings, local errors, and responsive containment.
  • Admin-only update availability notice that opens the manual private-repository workflow after a backup.
  • Beginner setup instructions and exact callback values beside Google OAuth, Resend, and Discord forms.
Before upgradingDownload an Entire installation backup. Then manually run Install or upgrade LancerLogin in the private deployment repository, choose Upgrade, keep latest selected, and verify the exact installation slug. The dashboard cannot start the deployment itself.

v0.5.0

Attendance lifecycle and operations home

Meetings now require an end time. Members scan on arrival and departure; one scan is active, a pair is present, and incomplete attendance becomes absent after one organization-wide late-scan allowance.

  • Rolling five-week Home calendar, live rosters, outstanding contest review, and a top-level Kiosks page.
  • Temporary guided onboarding that disappears after completion and remains reachable from settings.
  • Organization colors across light and dark appearances plus adaptive transparent-logo contrast.
  • Automatic five-minute Discord absence notices, signed recipient-only contest buttons, and reasoned audited review.
  • Legacy attendance credit preserved, missing legacy end times inferred at one hour, and v0.4 dashboard backups remain restorable.
  • Private deployment workflow defaults to the latest release and uses the supported first-secret upload path.
Before upgradingDownload an Entire installation backup. Then manually run Install or upgrade LancerLogin in the private deployment repository, choose Upgrade, keep latest selected, and verify the exact installation slug. Discord contest buttons require rotating the optional Discord configuration with its application public key and displayed Interactions Endpoint URL.
