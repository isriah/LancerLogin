v0.24.0 transition

Safe upgrades and in-app web updates

Clean public release history begins with v0.24.0. Historical development releases and download links are retired from this address. Read the v0.24.0 release notes for migration, configuration and acceptance details.

Before upgrading Save an Entire installation backup securely. Install the reviewed private controller and bridge web/Pi installation to v0.24.0 before V1.0.0 becomes latest. Then use Settings → Updates to prepare release notes, download and confirm the saved backup, start and track the web upgrade, and review any required GitHub environment approval. Command acceptance is not verified success.

Physical kiosk updates remain separate. Missed the bridge? Use the checksum-verified exact-v0.24.0 Pi bootstrap before updating to V1.0.0. Keep pairing, encryption secrets and pending attendance; never automatically restore D1.
