Reference

Architecture and security

How an installation is built and protected, with links to the detailed reference in the repository.

Components

P

Cloudflare Pages

The React dashboard plus a same-origin /api proxy, so sign-in cookies stay on your dashboard's own address. Pages holds no Cloudflare token.

W

Worker and D1

The API Worker handles authorization, validation, attendance, reports, exports, integrations, and scheduled work. D1 stores the installation's data.

K

Raspberry Pi kiosks

Each kiosk reads its input device, keeps its pairing, local links, and offline queue on the Pi, and sends scans to the Worker.

Modules add pages, routes, settings, and data to this structure. Attendance is built in; plugins are composed into the dashboard and Worker when the installation is built.

Security model

  • Admin and Operator permissions are enforced by the Worker on every request, not only hidden in the dashboard.
  • Sessions are signed, HTTP-only, Secure, SameSite=Strict cookies. Each protected request rechecks the account, role, and session.
  • Local passwords use salted scrypt hashes. Five wrong passwords pause sign-in to that account for 15 minutes.
  • Google sign-in validates the issuer, audience, verified email, and an active LancerLogin account.
  • Integration secrets are encrypted with AES-256-GCM using an installation-specific key and are never returned to the browser.
  • Pairing codes and kiosk credentials are stored only as hashes.
  • Meeting attendance windows cannot overlap, so each scan matches at most one meeting.
  • Kiosks accept six fixed, kiosk-specific commands from the dashboard and never a shell command or arbitrary argument.
  • Kiosk maintenance is available only on the kiosk's own screen, behind a rate-limited local PIN.
  • Dashboard updates install only complete official releases, pinned to an exact commit, after an entire-installation backup.
  • CSV exports store values that look like spreadsheet formulas as text.

Plugins run with the same access as LancerLogin itself. Add only plugins whose source you trust.
