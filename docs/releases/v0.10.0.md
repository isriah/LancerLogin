# LancerLogin v0.10.0 - Physical kiosk restoration and meeting workflow cleanup

## Highlights

- Restores the physical kiosk display to match the pre-community kiosk layout more closely, including the full-screen attendance surface, adaptive organization header, and protected fingerprint maintenance access.
- Adds kiosk-side PIN keypads for local networking and maintenance flows so touch-only deployments can create and unlock PIN-protected tools.
- Reworks fingerprint enrollment prompts around staged sensor feedback, themed action colors, and a no-scroll 800x480 maintenance window.
- Simplifies meetings to one date plus start/end times, autofills end time to 2.5 hours after the chosen start time, and removes the setup-only test meeting flow.
- Adds soft deletion for individual meetings and future meetings in a recurring series while preserving historical attendance and audit records.
- Automatically requests Discord calendar sync when meetings are created and adds a bulk sync action that reuses existing Discord event mappings instead of duplicating them.

## Data and Configuration

- Adds the `0010_meeting_soft_delete.sql` migration, which appends `deleted_at` to meetings and indexes active meeting schedule queries.
- Backup schema version is now 5 so meeting deletion state is preserved on export and restore.
- Dashboard release displays use plain semantic versions such as `0.10.0`; Git tags and release-note filenames continue to use the existing `v0.10.0` release automation convention.

## Known Limits

- One-click kiosk self-update from the dashboard remains queued. It needs an explicit decision for the persistent root-level update path before it is added.
- Existing v0.9.0 adopter/private deployment notes remain valid until this release is tagged and manually accepted.

## Verification

Before tagging, run:

```sh
npm run verify:release
```

For a physical Pi, also confirm the full-screen kiosk fit, fingerprint enrollment prompts, touch keypad entry, Wi-Fi scan list, and Discord calendar sync against the target deployment.
