# LancerLogin v0.10.1 - Pi desktop kiosk relaunch shortcut

## Highlights

- Adds a **LancerLogin Kiosk** desktop shortcut during Pi installation when Chromium is available.
- The shortcut reopens the local attendance screen in full-screen kiosk mode if the Pi is sitting at the desktop.
- The existing desktop-login autostart entry now uses the same launcher command as the shortcut.

## Data and Configuration

- No D1 migration is required.
- Existing roster, meetings, attendance, integrations, kiosk pairing, local queue, fingerprint mappings, and settings PIN are preserved.
- This is a kiosk installer/runtime packaging patch in the `0.10.x` line.

## Verification

- `npm run verify:kiosk`
- `npm run verify:docs`
- Physical Pi check: the desktop shortcut was clicked on the test Pi and Chromium reopened in full-screen kiosk mode.

## Known Limits

- One-click kiosk self-update from the dashboard remains gated pending exact approval of the persistent root update path.
- The private deployment workflow typed confirmation remains in place as an account-changing safety guard.
