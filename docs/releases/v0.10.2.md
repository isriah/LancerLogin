# LancerLogin v0.10.2 - Readability improvements across dashboard and kiosk

## Highlights

- Raises the desktop dashboard base type to 17px and enlarges dense operational table content, headers, labels, helper copy, and action buttons.
- Enlarges member-facing kiosk brand, scan-state, member, meeting, pairing, and operational-status text, retaining the compact 800x480 fallback.
- Makes protected fingerprint maintenance easier to use on the Pi touchscreen with 16px controls and mappings, larger enrollment prompts, and larger keypad labels.

## Data and Configuration

- No D1 migration is required.
- Existing roster, meetings, attendance, integrations, kiosk pairing, local queue, fingerprint mappings, and settings PIN are preserved.
- This is a visual/runtime patch in the `0.10.x` release line.

## Upgrade

1. Download an **Entire installation** backup from **Settings > Updates**.
2. In the adopter-owned private repository, manually run **Install or upgrade LancerLogin** with **Upgrade**, **Latest stable**, the existing installation slug, and its required confirmation.
3. On the Pi, install the matching `v0.10.2` guided installer or use the approved managed Pi update path.

## Verification

- `npm run verify:dashboard`
- `npm run verify:kiosk`
- `npm run verify:release`
- Physical Pi check: confirm ordinary kiosk text and PIN-protected fingerprint maintenance remain readable and fully contained at 800x480.

## Known Limits

- One-click kiosk self-update from the dashboard remains gated pending exact approval of the persistent root update path.
- The private deployment workflow typed confirmation remains in place as an account-changing safety guard.
- This release does not claim physical Pi acceptance; it is published for the requested typography review.
