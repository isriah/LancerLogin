# LancerLogin v0.10.4 - Durable Discord absence contests

## Fixes

- Re-sending a Discord absence notice no longer invalidates the contest button in the earlier message. Each sent message keeps its own authorized-recipient record.
- Discord absence-contest messages now expire after a configurable window, set to **24 hours** by default in **Settings → Organization**. The allowed range is 1 to 168 hours.
- An expired or account-mismatched button returns a specific private response and leaves attendance unchanged.

## Upgrade notes

1. Download an **Entire installation** backup from **Settings → Updates**.
2. In the private deployment repository, run **Install or upgrade LancerLogin** with **Upgrade**, **Latest stable**, and the existing installation slug.
3. After the upgrade, review **Settings → Organization → Discord contest window (hours)**. Existing notices from before the upgrade cannot gain historical recipient records; notices sent after the upgrade retain their own contest authorization until expiry.

This release applies `0011_discord_notice_history.sql` and `0012_discord_contest_window.sql` to preserve per-message recipient history and store the organization-wide expiry setting.
