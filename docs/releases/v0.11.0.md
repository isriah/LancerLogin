# LancerLogin v0.11.0 - Attendance operations and browser kiosk simulation

## Improvements

- Manual Present corrections no longer require a note. Attendance actions and contest resolutions report temporarily beside the affected member, while resolved contest audit cards no longer crowd the page.
- Attendance now distinguishes the primary Attendance rate from the Excuse-adjusted class rate. Reports add a sortable roster leaderboard, meeting-by-meeting team trend, outstanding contest list, member drilldown, saved local report range, and CSV export.
- Settings now separates organization branding, shared attendance Configuration, and dashboard Access management. Roster adds unified name/email/member-ID search and an active/all filter.
- Updates presents dashboard and kiosk installed/latest versions in matching comparisons.
- The browser simulator has a dedicated kiosk-like scan surface backed by the existing isolated simulator credential and audit workflow. Its browser controls cannot access physical R503 templates, saved Wi-Fi credentials, or the active hardware kiosk identity.

## Upgrade notes

1. The private deployment upgrade applies no new D1 migration for this release.
2. Upgrade the private installation to **Latest stable**. An online compatible Pi can then use its managed Latest stable kiosk update.

## Verification

- Compare a member's primary and excuse-adjusted report rates after recording an excuse.

## Known limits

- Browser simulator maintenance/network messaging is intentionally non-hardware: fingerprint templates, saved network profiles, and physical local PINs remain only on the Pi.
