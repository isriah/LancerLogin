# LancerLogin v0.12.0 - Roster and attendance operations

## Improvements

- Roster members can now be edited directly, activated or deactivated, and deleted only when no attendance history exists. The roster also shows a compact, audited history of recent imports.
- Each member can have an optional **Attendance required from** date. Meetings before that date appear as **Not required** and are excluded from both Attendance rate and Excuse-adjusted class rate calculations without deleting past records.
- Admins can clear one member's attendance events and corrections for one selected meeting through a confirmation-gated, audited recovery action.
- Meetings can be selected and soft-deleted in an arbitrary bulk set. Existing single-occurrence, future-series, and immediate undo workflows remain unchanged.

## Upgrade notes

1. The private deployment upgrade applies D1 migration `0013_roster_operations.sql`, which adds the nullable member requirement date and its index.
2. Existing members retain a blank requirement date, so historical reporting is unchanged until an Admin assigns one.
3. This is a dashboard and Worker release. No Pi installer or kiosk update is required.
