# LancerLogin v0.12.1 - Mobile dashboard fit and reachability

## Improvements

- Phone-width dashboard navigation now wraps into touch-sized rows instead of creating a horizontal scrollbar.
- Mobile reports present each member's rates in a compact stacked row, and the calendar fits all seven days without a horizontal strip.
- The meetings directory keeps its date, start, end, and actions visible on a phone while hiding lower-priority columns.
- Organization color editors now use one full-width card and stack RGB number fields above their sliders, preventing clipped controls.
- Other operational headers and action areas stack cleanly at phone widths.

## Upgrade notes

This is a dashboard-only release. It has no database migration, configuration change, or Raspberry Pi kiosk update.
