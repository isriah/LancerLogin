# LancerLogin v0.12.2 - Mobile navigation drawer

## Improvements

- On phone-sized screens, the primary dashboard navigation is now a left-side drawer opened with a three-bar menu control.
- The drawer has full-size links, closes after navigation, and can be dismissed by tapping outside it.
- Settings categories remain visible within Settings, while the main dashboard destinations no longer occupy a wrapped or horizontally scrolling strip.

## Upgrade notes

This is a dashboard-only release. It has no database migration, configuration change, or Raspberry Pi kiosk update.
