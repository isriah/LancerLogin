# LancerLogin v0.12.3 - Mobile meeting layout and safer data controls

## Improvements

- Phone-sized meeting rows now show date, start, and end together under the title, with Edit, Sync Discord, and Delete controls on a full-width row below.
- Meeting list bulk actions have consistent vertical spacing, and the meeting creation form uses tighter, predictable spacing between related fields.
- Add member now owns CSV import in the same dialog, keeping roster actions together.
- Privacy settings and documentation use a concise anonymous-reporting summary and clearly state the categories that are never included.
- Restore file controls are centered, and data deletion requires an exact typed confirmation before it becomes available.

## Upgrade notes

This is a dashboard-only release. It has no database migration, configuration change, or Raspberry Pi kiosk update.
