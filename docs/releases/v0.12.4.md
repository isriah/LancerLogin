# LancerLogin v0.12.4 - Clearer project guide and mobile drawer cleanup

## Improvements

- The repository README now plainly lists supported features, supported Raspberry Pi kiosk hardware, and the installation and upgrade sequence.
- Opening the phone navigation drawer removes the three-bar menu trigger, so it no longer overlaps drawer content. Tapping the dimmed area closes the drawer and returns the trigger.

## Upgrade notes

This is a dashboard and documentation-only release. It has no database migration, configuration change, or Raspberry Pi kiosk update.
