# LancerLogin v0.12.6 - Direct calendar-to-attendance navigation

## Changed

- The Attendance meeting selector now lists meetings from oldest to newest.
- Selecting a meeting from the Home calendar now opens that exact meeting in Attendance.
- Attendance deep links use `/attendance?meetingId=<meeting-id>`, so the selected meeting survives browser navigation and can be shared within an authenticated dashboard session.

## Upgrade impact

- No database migration, configuration change, kiosk change, or Pi installer update is required.
- This is a dashboard-only update.

## Verification

- Dashboard tests and type-check pass.
- Chromium dashboard and kiosk regression tests pass.
