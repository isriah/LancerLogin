# LancerLogin v0.12.7 - Visible updates and reliable kiosk requests

## Changed

- Added a prominent, dismissible update-available popup across the authenticated dashboard, including Home. A dismissal applies only to that specific available release.
- Moved Guided Setup from Organization into its own Settings sub-tab.
- Added durable kiosk-update command status. The Updates page now distinguishes a queued request, kiosk receipt, installer start, installed version confirmation, and an actionable failure.
- Added the required D1 migration for the existing `install_latest` kiosk command. Earlier installations could show the update action but could not persist that command because the database constraint did not yet allow it.

## Upgrade impact

- The dashboard deployment applies migration `0014_kiosk_update_commands.sql`; it preserves existing kiosk command history while allowing the verified latest-stable update command.
- No Pi installer change is required. Once the dashboard is upgraded, an online compatible kiosk can receive the pending command through its existing polling service.

## Verification

- D1 migration verification passed across the full migration chain.
- API and dashboard tests, TypeScript checks, production build, and Chromium desktop/mobile/kiosk regression tests passed.
