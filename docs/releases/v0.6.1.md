# LancerLogin v0.6.1 — Kiosk status badge spacing

This patch improves the kiosk status rows reported during v0.6.0 acceptance testing.

## What changed

- Physical-kiosk and browser-simulator names now share a wrapping layout row with their status badge.
- Status badges have more horizontal padding and a consistent gap from the kiosk name at full and narrow window widths.

## Data and configuration

This release has no database migration or configuration change. It does not alter kiosk pairing, simulator behavior, attendance, or credentials.

## Upgrade

Download an **Entire installation** backup from **Settings → Updates**, then manually run **Install or upgrade LancerLogin** in the private deployment repository. Choose **Upgrade** and **latest**, enter the existing installation slug, and type the required confirmation. The dashboard does not dispatch the workflow automatically.

## Verification

Open **Kiosks** at full width and at a narrow browser width. Confirm that **Not paired**, **Online**, and **Offline** badges have visible interior spacing and remain separated from the corresponding kiosk name.
