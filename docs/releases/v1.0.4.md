# v1.0.4 - Stable Community source baseline

This release establishes a fresh stable Community source baseline with versioned installer, ARM64 and ARMv7 kiosk archives, and SHA-256 checksums. Application behavior matches v1.0.3. There are no database migrations or new installation settings.

The public repository provides stable Community source on main. Its modular branch is reserved for a future Modular publication and contains no application files. Earlier public releases and version tags are retired after this release is published. Historical release notes remain reference material; their retired downloads are unavailable.

## Installation and updates

New installations use the v1.0.4 installer and private deployment template. Existing v1.0.3 installations can continue running. To update the dashboard, use the supported backup-first web update and verify direct API health, dashboard release identity, and same-origin proxy health after completion. Physical kiosk updates are separate and require their own operator approval.

## Verification boundary

Publication requires complete repository verification, the full browser suite, strict dependency audit, and Linux kiosk artifact checks on the exact public commit. Release packaging validates the installer, both ARM archives, checksums, and extracted service as an unprivileged Linux identity. These checks do not establish live installation, physical sensor, enrollment, or attendance operation.
