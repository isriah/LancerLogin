This release makes the dashboard easier to navigate and the kiosk simulator more faithful to the real kiosk. It also improves meeting calendar updates and makes Discord kiosk status easier to find.

## Bugs fixed

- Google Calendar events now use the meeting's actual title and notes, including later edits.
- Simulator scans now record arrivals and departures without requiring a manual scan action.
- Simulator member and meeting selectors follow the dashboard theme, and the scan button is centered.
- Roster names and member IDs have clear spacing, and the extra gap between names and email addresses is removed.
- Access email addresses retain their lowercase display.
- Discord calendar updates work for meetings already in progress. Meetings that started before their first sync show a clear explanation so upcoming meetings can be synced in advance.
- Discord status sync checks that the existing message is still present and replaces it if it was deleted.

## Features added

- A compact header keeps the organization and navigation together, with Roster before Reports.
- Theme and sign-out controls are available in Settings.
- Meeting weights are now in Settings > Configuration.
- The kiosk simulator reflects the real kiosk's branding, feedback and footer layout.
- Discord kiosk-status sync provides a direct link to the status message.
- Member participation start dates remain available in the Edit member popup while the roster table stays compact.

## Features removed

None.
