This release makes it easier to update a roster from an exported CSV file or copied spreadsheet rows. Preview the changes before confirming an import.

## Bugs fixed

- The CSV file chooser now opens only when you select the Choose File button, not when you select its label or filename.
- The Back to one member button in the roster import popup now follows the dashboard theme and returns keyboard focus to Member ID.

## Features added

- Upload a CSV roster directly from the import popup. The file contents remain editable before previewing.
- Paste tab-separated spreadsheet rows, including rows without a header when the columns are member ID, first name, last name, email, and optional Discord ID.

## Features removed

None.
