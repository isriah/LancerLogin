LancerLogin 1.1.2 separates regular attendance from configurable attendance policies. Organizations can configure Class as an ordinary policy label and choose how excused meetings affect its percentage.

## Bugs fixed

- Regular attendance is calculated independently from assigned percentage and weekly policies, including their meeting weights and reporting windows.
- Roster, Reports, member profiles, dashboard alerts, email, Discord, and CSV exports now use the same explicit regular and policy results.
- Policy previews include historical result changes even when current compliance is unchanged.

## Features added

- Percentage policies can exclude excused meetings or count them as missed. Existing and new rules default to exclusion.
- Roster, Reports, and member profiles show Regular attendance alongside the named assigned policy. Weekly policies show attended and target meeting counts.
- CSV exports include explicit regular and policy results, periods, label, type, target, counts, status, and excuse handling.

## Features removed

- The universal Class percentage is no longer shown. Configure Class as a policy label and assign it to the members who use that rule.

## Installation and update

1. Back up the entire installation before updating. In **Settings → Updates**, use **Back up and begin update**, download and confirm the backup, then choose **Start update to v1.1.2**. Verify the dashboard and API report v1.1.2 after completion.
2. To use Class attendance, open **Settings → Attendance policy**, create or select the Class label, add a weighted percentage rule, choose how excused meetings are handled, and assign the label to the applicable members.
3. If another system imports attendance CSV files, update it for the new explicit regular and policy columns documented in the attendance policy guide.

This release applies migration 0034 to store percentage-policy excuse handling. Existing rules and older backups default to excluding excused meetings. It does not require attendance data restoration.
