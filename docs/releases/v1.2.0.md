LancerLogin 1.2.0 adds a saved-report workspace with routed tabs, configurable columns, pagination, and personal or shared report libraries. It also refines attendance-policy, roster, meeting, Settings, and mobile dashboard workflows.

## Bugs fixed

- Browse reports, label filters, and report column menus now dismiss when focus moves elsewhere, stay attached while scrolling, and remain inside desktop and mobile viewports.
- Reports, attendance tables, member actions, information tips, Settings controls, and kiosk actions now use available space more consistently across custom branding, light and dark themes, and supported screen sizes.
- Meeting attendance names link to member profiles, empty contest sections stay hidden, and related meeting and kiosk operations use compact shared action groups.

## Features added

- Reports now provide a fixed paginated Leaderboard plus routed personal and shared report tabs with account-synced pinning, search, direct links, and one unsaved draft.
- Saved reports support rolling or fixed periods, roster and meeting filters, multi-label matching, current or historical membership, ordered curated columns, header-based sorting and filtering, and read-only viewing until Edit is selected.
- Report CSV exports follow the selected columns and order, while detailed attendance CSV exports preserve filtered meeting-level records. Both export every matching row and keep spreadsheet protections.
- Members may hold more than one attendance-policy label at the same time. Each active policy is calculated and displayed independently alongside Regular attendance.
- Each user can enable Debug mode to reveal diagnostic label history, current-label attendance history, and recent roster imports for that account.

## Features removed

- The single browser-local saved attendance view is replaced by the saved report library. An existing local view is offered once as an imported draft until it is saved or dismissed.

## Installation and update

1. Back up the entire installation before updating. In **Settings → Updates**, use **Back up and begin update**, download and confirm the backup, then choose **Start update to v1.2.0**.
2. After completion, verify that the dashboard and API both report v1.2.0. Open **Reports** and confirm the Leaderboard and saved-report controls load for an Administrator or Operator.
3. Review any preserved browser-local report view in **Browse reports**, then save it into the personal or shared library or dismiss it.

This release applies migration 0035 for per-user Debug mode and migration 0036 for saved report views and pinned tabs. Entire-installation backups advance to schema 20 and include saved reports and tab preferences. Older backups remain supported and restore with an empty report library. No attendance data restoration is required.
