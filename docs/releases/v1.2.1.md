LancerLogin 1.2.1 reduces D1 row reads for attendance reports and meeting attendance, and pauses recurring dashboard refreshes while their browser tab is hidden.

## Bugs fixed

- Meeting attendance and contest lookups use additional indexes to avoid repeated history scans.
- Individual attendance reports load the selected member's history. Meeting absence notifications load the selected meeting's attendance data.
- Repeated reports can reuse source data for up to five minutes. Database revision checks invalidate the cache after relevant changes, while authorization and time-sensitive attendance calculations still run on every request.
- Recurring dashboard refreshes wait for the previous request to finish and pause in hidden tabs.
- Cleanup and meeting-series operation counts remain accurate when database triggers perform additional writes.

## Diagnostics added

- Worker logs include numeric D1 usage counters for report requests and expensive requests without recording attendance values, query parameters or member identifiers.
- An account usage reporting script groups database usage and identifies 50%, 75% and 90% daily-budget thresholds. See [D1 usage](../D1-USAGE.md) for installation-owned monitoring and measurement limits.

## Installation and update

1. In **Settings → Updates**, back up the entire installation, download and confirm the backup, then start the update to v1.2.1.
2. After completion, verify that both the dashboard and API report v1.2.1. Check a team report, an individual report and a meeting attendance view.
3. Compare Cloudflare row reads per request after the update, accounting for traffic changes and analytics delays.

Migration 0037 adds indexes and an operational cache revision table with invalidation triggers. Existing attendance data is preserved. The operational table is excluded from portable backups; ordinary data restores invalidate cached source data through the triggers. Indexes and triggers add write overhead, so monitor both read and write usage. This release does not change the Cloudflare plan or daily allowance.
