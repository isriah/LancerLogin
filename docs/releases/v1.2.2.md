LancerLogin 1.2.2 adds guided page walkthroughs, attendance corrections from member history, and clearer reporting. The guides remember your progress and help you explore the dashboard, reports, and kiosk management.

## Bugs fixed

- Saved reports using Current membership now apply today's labels throughout the selected report period, including CSV exports. Historical membership continues to use the labels held on each meeting date.
- Browse reports popups use the correct light or dark theme.
- Member profile controls and attendance history fit smaller screens more clearly.

## Features added

- Walkthroughs for Dashboard, Roster, member profiles, Reports, meeting attendance, Kiosks, and the browser simulator, with progress saved to each account and reset controls in Debug mode.
- Safe Dashboard practice for meeting views, searches, selections, and forms.
- An optional Monthly attendance example in the Reports guide. It stays saved as a personal report that you can edit or delete later.
- Kiosk management guidance covering pairing, naming, fingerprint maintenance, restarts, PIN recovery, updates, and retirement. If no physical kiosk is paired, the guide shows an example with disabled controls.
- Present, Excuse, and Absent actions in each member's attendance history, plus Clear for Administrators.

## Features removed

- The roster's explanatory attendance-baseline text.
