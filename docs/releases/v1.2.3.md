LancerLogin 1.2.3 keeps update checks working when the server and your computer's clock differ slightly.

## Bugs fixed

- A valid release check no longer fails and repeatedly postpones the next attempt when the server timestamp is slightly ahead of your computer.
- Confirmed release information stays available after reloading the page, while expired information and provider cooldowns continue to be respected.

## Features added

None.

## Features removed

None.

## Updating an affected installation

If an older dashboard keeps postponing release checks because of a clock difference:

1. Synchronize your computer's clock using its automatic date and time setting. In **Settings → Updates**, wait for the displayed retry time and choose **Check for updates** if needed.
2. After v1.2.3 is confirmed, choose **Back up and begin update**, then **Download entire-installation backup**. Save the file securely and select the saved-backup confirmation.
3. Choose **Start update to v1.2.3**. Use **Reload updated dashboard** after verified completion, then confirm the Dashboard card shows version 1.2.3.

If release checks still fail, ask your installation maintainer to arrange an exact-release update through the private deployment controller with the required backup. Publishing this fix does not replace an older dashboard that is already running.
