LancerLogin 1.2.4 makes dashboard updates more dependable and keeps update status, release notes, and reload prompts aligned with what is actually installed.

## Bugs fixed

- Completed updates no longer replace the current status or release notes with an older update request. Previous update details remain available under Diagnostics and manual recovery.
- Reload prompts compare the Worker, Pages deployment, and current browser tab. They stop appearing once the updated dashboard is loaded and no longer persist because of an older completed request.
- Release checks use the browser's receipt time and bounded retry delays, preventing server or computer clock differences from postponing checks indefinitely.
- Web updates preserve and verify the configured dashboard origin, allow more time for deployment propagation, and verify both the standard Pages address and a configured custom domain.
- GitHub rate limits, missing permissions, invalid workflows, and credentials that expire too soon now produce distinct guidance before an unsafe update can start.
- A later verified release can safely supersede an older recovery request without leaving installation writes paused.

## Features added

- The Updates page now shows the Worker release, the release served by Pages, and the release running in the current browser tab. Starting another update remains unavailable while those deployed releases disagree.

## Features removed

None.

## Updating an affected installation

If v1.2.3 continues to show notes or a reload prompt for an older update:

1. Open **Settings → Updates** and confirm that v1.2.4 is available.
2. Choose **Back up and begin update**, then **Download entire-installation backup**. Save the file securely and select the saved-backup confirmation.
3. Choose **Start update to v1.2.4** and complete the production approval in GitHub if your installation requires it.
4. After verification completes, choose **Reload updated dashboard**. Confirm that the Dashboard card reports 1.2.4 for the installed and Pages releases and that the current tab no longer needs a reload.
