LancerLogin 1.2.5 makes Discord absence notices reliable when a meeting has a large number of linked absent members.

## Bugs fixed

- Large recipient lists are split automatically so attendance notices stay within Discord's message-content and mention limits.
- A retry after an interrupted multi-message send continues with the remaining members instead of mentioning members whose message was already delivered.
- Every message in a multi-part notice is removed after the configured contest window.

## Features added

None.

## Features removed

None.

## After updating

If an absence notice previously failed, open the affected meeting and choose **Send Discord absence notice** again.
