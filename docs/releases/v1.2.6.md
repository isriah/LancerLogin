# LancerLogin v1.2.6

This Community bridge adds installation-wide Stable and Beta update tracks without changing the attendance workflow. It prepares existing installations for an optional move to Modular.

## Bugs fixed

None.

## Features added

- Admins can save a Stable or explicitly acknowledged Beta track in Settings → Updates.
- Web and kiosk updates pin the selected official release and commit, with separate track caches and unchanged backup-first web controls.
- A channel-aware kiosk helper retains pairing, local configuration and queued scans.
- Existing Community installations have an in-place path to opt in to Modular without replacing their roster, settings or database.

## Features removed

None.

## Required adopter actions for Beta

Stable remains the default. Before opting in, install this bridge on the dashboard and each physical kiosk, and have the maintainer review and update the existing private controller. Saving Beta starts no update. Returning to Stable never downgrades an installed beta. Follow [Stable and Beta update tracks](../UPDATE-TRACKS.md).
