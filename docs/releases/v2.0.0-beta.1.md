# LancerLogin v2.0.0-beta.1

The first Modular beta keeps Community Attendance as the baseline and adds optional Outreach and Carpool workflows, multiple kiosks and installation-wide update tracks. Enable only the modules and integrations your organization needs.

## Bugs fixed

None.

## Features added

- Optional modules have separate setup, permissions and retained data. Existing Community Attendance remains enabled during an in-place upgrade.
- Outreach supports member-submitted participation, staff corrections and manual exceptions, scheduled activities, labels, supported teams and reports.
- Carpool supports CSV mapping and corrections, location review, round-trip assignments, drag-and-drop editing, exports and optional meeting quick-links.
- Multiple uniquely paired kiosks can record attendance and replay offline scans independently.
- Optional fingerprint sharing supports cross-network encrypted peer transfers or separately consented server-encrypted storage for provisioning new kiosks.
- Kiosks can use fingerprint, member ID or supported keyboard-wedge RFID, NFC and QR inputs. Validate your chosen reader hardware before relying on it.
- A PIN-protected local unpair action safely archives installation-bound state before pairing to another installation.
- Admins can explicitly choose Stable or Beta updates without installing automatically or downgrading.

## Features removed

None.

## Upgrade from Community

1. Preserve the entire-installation backup, provider secrets and each kiosk's protected local state.
2. Install the stable v1.2.6 Community bridge on the dashboard and every physical kiosk. Have the maintainer update the existing private controller as described in [Update tracks](../UPDATE-TRACKS.md).
3. Choose Beta in Settings → Updates, acknowledge and save. Prepare this release, review the notes, download and save a new associated backup, then choose Start update.
4. Wait for verified completion, reload and compare the roster, settings, reports, attendance, integrations and kiosk identities. Update each kiosk separately without re-imaging it.
5. Re-enroll members online before sharing existing fingerprints. Software updates retain reader templates and mappings; a mappings reset is a separate explicit action and never erases reader templates.

Follow [Community upgrade](../COMMUNITY-UPGRADE.md) for carry-over and recovery checks. Outreach, Carpool and fingerprint sharing start disabled. Returning to Stable does not downgrade this beta; wait for a newer stable release.
