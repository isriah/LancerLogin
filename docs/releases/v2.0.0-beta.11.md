# LancerLogin v2.0.0-beta.11

This beta greatly reduces the Cloudflare D1 database reads used when kiosks keep scans that need review. Update the dashboard first, then update each kiosk with **Update kiosk** on the Kiosks page.

## Bugs fixed

- A kiosk keeping many scans that need review no longer uses up the Cloudflare D1 free plan's daily read allowance. Kiosks now send a retained scan again only when its review changes or during an hourly check, and the dashboard reads only the scans each kiosk sends.
