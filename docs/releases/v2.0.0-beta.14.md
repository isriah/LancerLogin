# LancerLogin v2.0.0-beta.14

This beta helps prevent kiosks from checking in or out the wrong member. Kiosks now record how confident each fingerprint match is, and an Admin can require a minimum so weak matches are asked to scan again instead of being recorded under someone else's name. The Kiosks page also explains why a kiosk needs attention, and kiosk readers can erase retired fingerprints to free space for new enrollments. Update the dashboard first, then update each kiosk with **Update kiosk** on the Kiosks page.

## Bugs fixed

- A rejected scan reviewed in the dashboard now clears the kiosk's warning within about two minutes. The kiosk previously kept the warning for up to an hour.
- A kiosk now shows **Fingerprint not recognized** for an unrecognized fingerprint in the first few seconds after it starts. The message was previously hidden.

## Features added

- The Kiosks page names the reason a kiosk needs attention under **Needs attention**: rejected scans waiting for review, a clock that is not confirmed, scans saved while the clock was unconfirmed, scans waiting to upload, or rejected scans that could not be sent for review.
- **Fingerprint matching** on the Kiosks page shows how confident fingerprint matches were over the last 30 days. Admins can set a **Minimum match score**; below it, the kiosk asks the member to place their finger again instead of checking them in or out. The minimum starts at 0, which accepts every match as before. Choose a value below the scores members normally get, so only weak matches are asked to scan again. **Manage kiosk > Diagnostics** shows how many weak matches each kiosk asked to rescan.
- **Manage kiosk > Diagnostics** shows how many fingerprints the kiosk's reader stores and how many are linked to members. Retired and replaced fingerprints stay on the reader and take up its 200 slots. When some are unlinked, **Device maintenance** offers **Erase unlinked fingerprints**, which erases only fingerprints no member is linked to. Erased fingerprints cannot be recovered.

## Features removed

None.

## Required actions

1. **Update the dashboard first**, then update each kiosk with **Update kiosk** on the Kiosks page. The new kiosk details, match scores, minimum match score and **Erase unlinked fingerprints** need the kiosk on this release.
