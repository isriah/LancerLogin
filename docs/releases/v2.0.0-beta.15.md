# LancerLogin v2.0.0-beta.15

This beta lets plugins do more without holding their own copies of your credentials, and puts you in control of what one plugin may do in another. Plugins can now send email through your verified Resend connection, use your installation's time zone, and serve public pages with more than one page, such as a booking page and a page for changing a booking. When a plugin asks to work with another module, for example to record guest visits as Outreach team support, an Administrator reviews and grants that access in **Settings > Modules**. Existing installations need no action.

## Bugs fixed

- A public page address with a trailing slash, such as `/submit-hours/`, now opens the page instead of the signed-in dashboard.

## Features added

- **Settings > Modules > Module access** lists what each installed plugin asks to do in another module, in plain language with its reason, and whether it is granted. Administrators grant or revoke each request after confirming their identity, the same way they change plugins. Revoking takes effect at once. Grants and revocations are recorded in the audit log, and a grant is not restored from a backup. The section appears only when an installed plugin asks for access.
- Plugins can send email through the installation's Resend connection once it is verified. Resend keeps its key in LancerLogin; plugins never receive it.
- Plugins can show public pages with their own sub-pages, so a booking page and the page a confirmation email links to can live under one address.

## Features removed

None.
