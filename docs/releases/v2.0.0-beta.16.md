# LancerLogin v2.0.0-beta.16

This beta includes the Outreach plugin v1.1.0, which lets other plugins record team support in Outreach, and fixes the layout of two module screens. Guest Visits can now record a visit as Team Support once an Administrator grants it access in **Settings > Modules > Module access**. Existing installations need no action.

## Bugs fixed

- The notice for a module whose setup is not finished now uses the card's full width, with its button beside the text, or below it on phones. Before, the text was squeezed into a narrow column and the button ran past the edge of the card.
- In **Settings > Modules**, the **Confirm disable** and **Cancel** buttons are now the same height and line up.

## Features added

- The included Outreach plugin is now v1.1.0. Other plugins can find supported teams, add a supported team and create a Team Support activity through Outreach, with an Administrator's grant or for a signed-in user who can manage Outreach. Each request is safe to repeat, refuses archived teams and is recorded in the audit log with the plugin that made it. Existing Outreach data is unchanged.

## Features removed

None.
