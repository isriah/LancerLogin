# LancerLogin v2.0.0-beta.18

This beta fixes setup problems found while rewriting the documentation, makes the kiosk pairing screen readable, and gives new installations red and gold starting colors. Existing installations need no action and keep their colors.

## Bugs fixed

- First-time setup could skip the **Attendance is ready** screen and go straight to Meetings if you spent more than about 30 seconds on the optional Calendar or Discord cards. Setup now stays open until you reach the completion screen.
- **Choose modules** no longer shows "Disabled" under a module you have switched on. It now says "Turns on when you continue", or "Turns on when you save" and "Turns off when you save" in **Settings > Modules**.
- The note under **Finish setup later** no longer says Attendance "becomes available" after every required step is already complete.
- The **Ready**, **Action needed** and **Optional** labels on Attendance setup cards are styled as badges again.
- Meeting times in Attendance setup no longer show seconds.
- On the kiosk's **Pair this kiosk** screen, the instructions were very hard to read and the setup-code hint was cut off at the bottom of the 800 x 480 display. Everything now fits on screen and the text is easy to read.
- The Organization settings page no longer mentions an organization appearance setting that does not exist.

## Features added

- New installations start with red (`#b80100`) and gold (`#eeb822`) organization colors. Change them in **Settings > Organization**.
- The documentation explains that **Light mode** in the Settings bar is each person's choice, saved in their browser.
- New documentation screenshots for first-time setup and kiosk pairing.

## Features removed

- None.
