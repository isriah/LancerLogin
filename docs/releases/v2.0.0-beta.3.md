# LancerLogin v2.0.0-beta.3

This beta makes Outreach activities easier to manage and gives Carpool a clearer workflow for reviewing people, building groups, and sharing plans.

## Bugs fixed

- Outreach time pickers close when clicking outside them. Unselected fields stay blank, and pressing Enter in submission fields does not send hours.
- Expanding participation details keeps button and column sizes steady. Submission log paging stays at the bottom of the screen without covering entries.
- Outreach submission logs show the newest logged entries first, and staff member lists are alphabetical.
- Carpool preserves staff edits during imports and checks assignment changes before saving them.

## Features added

- Edit all Outreach activity values and individual participation entries. Deleting participation excludes its hours while retaining its history.
- Publish Outreach events through compact destination icons. Events without times use all-day calendar entries, and reporting can reopen for 24 hours.
- Manage Outreach settings through General, Supported teams, and Labels tabs with search and paging.
- Configure the Carpool API key and preferred radius in Settings. The default radius is four miles and can be changed.
- Organize Carpool plans into People, Groups, and Share, with reviewed CSV imports, editable people, group rebuild previews and undo, and saved-plan sharing previews.

## Features removed

- Redundant Outreach activity navigation, close, refresh, and separate publication/reporting cards.
- The duplicate Kiosk Simulator link under Attendance settings.
