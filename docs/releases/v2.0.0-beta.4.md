# LancerLogin v2.0.0-beta.4

This beta makes kiosk enrollment easier, reduces background cloud usage, and speeds up Roster and Reports. Common dashboard controls are also easier to find.

## Bugs fixed

- Idle kiosks use less cloud database capacity while keeping fingerprint sync and remote commands responsive.
- Roster and Reports load sooner, and larger reports avoid repeating the same calculations.
- Outreach time pickers return keyboard focus to the selected control when finished or cancelled.
- Bulk contest acceptance sends one request for up to 100 selected contests, keeps individual decisions and audit records, and refreshes attendance once.
- Fingerprint state locks release when a kiosk process exits. Protected or incomplete recovery state still requires review.
- Enrollment verifies the current roster identity before writing to the reader. Maintenance scans cannot record attendance, and enrollment requires finger removal before attendance can resume.
- Roster lists scroll when a kiosk display reports a swipe as mouse input. Small movements on the logo no longer start native image dragging.
- People with no remaining counted hours disappear from an activity's logged participation list. Deleted entry history is retained.
- Past Outreach events can be published manually to Google Calendar. Automatic publication and Discord retain their future-event requirements.
- Narrow attendance trend charts put every date number on a consistent second line when labels need more room.

## Features added

- Larger kiosk member search and confirmation, a persistent keyboard number row, and a fixed alphabet/symbol toggle position.
- Automatic reader testing in maintenance, separate fingerprint sync diagnostics, and a single-line kiosk name and status footer.
- Exit to desktop closes the dedicated kiosk browser while the local service and queued attendance continue running.
- Compact fingerprint sharing controls with additional information in tooltips. Fingerprint recovery is under Settings, and Outreach settings are in the main Settings area.
- Meeting actions appear beside Edit, Duplicate and Delete. Roster search and label filters share a desktop row, and the Show filter includes an icon.

## Features removed

- Typed confirmation for deleting an Outreach participation entry. Staff reasons and revision history are retained.
- The meeting switcher, Refresh attendance button, and Active roster summary card.
- Excess spacing in the Reports Add column picker.
