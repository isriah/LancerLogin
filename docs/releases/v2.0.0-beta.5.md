# LancerLogin v2.0.0-beta.5

This beta makes the dashboard easier to use on phones, simplifies kiosk management, and improves reports and fingerprint synchronization.

## Bugs fixed

- Dashboard columns, buttons, dialogs and menus fit smaller screens with more consistent spacing and touch targets.
- Fingerprint synchronization preserves enrollment identity across retries and avoids downloading unchanged catalogs.
- Installation maintenance pauses kiosk polling work and scheduled operations consistently.
- Kiosk desktop shortcuts open the installed application, and the name and status footer fits Linux displays.

## Features added

- Calendar-first Dashboard and Outreach views with compact calendar/table switches.
- Compact roster records, leaderboards, member history and report tables, with editing actions grouped behind pencil controls.
- A Manage kiosk page for each device, with diagnostics, authentication settings, maintenance and retirement controls. Authentication can be configured independently for each kiosk.
- Fingerprint sharing in Settings, compact Settings navigation, and switch controls for Light mode and Debug.
- More flexible member reports, clearer exports and charts, and prompts for unsaved report changes.
- Undo for meeting deletion during the current session.
- Automatic lookup of saved Carpool addresses, with retry controls when lookup fails.

## Features removed

- Kiosk updates from Settings Updates. Update each device from Kiosks instead.
- Retired peer fingerprint-sharing controls. Cloud storage is the supported synchronization path.
- Redundant calendar selectors, the Outreach Activities toggle and the recent roster imports card.
