# LancerLogin v2.0.0-beta.6

This beta improves offline attendance recovery, brings rejected-scan review to the dashboard, and adds more flexible contest handling and report filters.

## Bugs fixed

- Kiosks that boot without a trusted clock pause attendance and offer PIN-protected date/time confirmation for offline use. Saved scans retain clock information through a reboot.
- Network clock corrections no longer interrupt an active kiosk screen.
- Meeting edits and duplicates preserve schedules, calendar selections remain stable, and first-meeting setup works around midnight.
- Outreach searches retain the correct results when filters change.
- Compact roster and leaderboard layouts display correctly on mobile, and deferred walkthrough invitations stay dismissed for the current browser session.

## Features added

- Start fingerprint enrollment from the dashboard on a selected kiosk, with physical confirmation and a limited enrollment session.
- Administrators can review rejected kiosk scans on the dashboard, inspect rejection reasons and clock evidence, and save review notes. Review status synchronizes with the kiosk; marking a scan reviewed does not change attendance.
- Reject multiple contests together. Members can contest again after rejection unless an administrator enables the setting to block re-contests. Earlier decisions remain in the history.
- Report filters for exact values, maximums, inclusive ranges, empty values and non-empty values.
- A guide for authors extending the application with bundled modules.

## Features removed

None.
