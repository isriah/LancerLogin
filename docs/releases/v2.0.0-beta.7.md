# LancerLogin v2.0.0-beta.7

This beta adds bulk dismissal of rejected kiosk scans, restores detailed desktop calendars, and improves attendance warning labels and kiosk service restart recovery.

## Bugs fixed

- An active kiosk attendance screen can resume after a short, orderly service restart while its existing page lease remains valid. Operator screens and expired sessions continue to keep scanning paused. This recovery does not restore expired sessions or carry them across a crash or an operating-system reboot.
- Desktop meeting and Outreach calendars show their scheduled entries again, while mobile calendars retain compact day indicators.

## Features added

- Administrators can filter rejected scans by kiosk and rejection reason, select individual records, a page or all matching records, and dismiss up to 500 scans together with a shared review note. The selection is fixed to the loaded records, so new uploads are not included. Larger sets require a narrower filter or a selected page.
- Each newly dismissed scan receives its own audit entry. Evidence is retained, attendance is unchanged, and existing review notes are preserved. Reviewed status synchronizes back to the originating kiosks.
- Attendance requirement warnings use consistent pill styling in light and dark themes, including narrow screens.

## Features removed

None.
