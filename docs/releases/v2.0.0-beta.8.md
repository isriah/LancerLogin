# LancerLogin v2.0.0-beta.8

This beta gives the desktop dashboard a consistent layout. Cards, headings, buttons, calendars and expandable sections now share the same spacing and styling on every page, and several controls that looked broken now display correctly.

## Bugs fixed

- Switches that are turned off now show their knob instead of an empty track.
- Drop-down menus on Roster, Kiosks, Access and Attendance settings show their arrow again.
- The Manage kiosk action and links inside page text no longer appear as plain browser-blue links.
- The Dashboard heading no longer shows a focus outline when the page loads.
- Integration information buttons no longer appear inside grey boxes.
- Outreach settings no longer show the narrow-screen section menu beside the desktop section tabs.
- Roster add and edit dialogs reliably move keyboard focus to an error message when saving or deleting fails.

## Features added

- Desktop cards use the same padding and heading height across every page, and calendar headings, month controls, day grids and selected-day details share one alignment. Today sits beside the month controls.
- Action buttons, back links and expandable sections use one consistent style throughout the desktop dashboard.
- The meeting attendance count now appears in the Attendance card heading, and the meeting details grid no longer shows empty grey cells.
- The Modules settings page, kiosk management page and Carpool event controls use the same compact layout as the rest of the dashboard.

## Features removed

None.
