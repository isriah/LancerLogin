# LancerLogin v2.0.0-beta.9

This beta fixes Beta updates for physical kiosks. Kiosks now tell the dashboard that their installed update helper can accept Beta releases, so Administrators can update them from the Kiosks page instead of seeing an update-channel bridge message.

## Bugs fixed

- A kiosk with the current update helper installed no longer shows "Install the stable update-channel bridge on this kiosk before updating it to Beta." when an Administrator updates it to a Beta release from the Kiosks page.

## Features added

None.

## Features removed

None.

## Update existing kiosks once

Kiosks running v2.0.0-beta.8 or earlier cannot receive this fix through **Update kiosk**, because they still report the earlier update readiness. Update each physical kiosk once with the release installer. Kiosks installed later, and every later Beta update, use **Update kiosk** as normal.

1. On the **Kiosks** page, confirm the kiosk is online and has no pending scans.
2. Preserve a private checkpoint of the kiosk's local state as described in [kiosk operations](../KIOSK.md#update-a-physical-kiosk). Keep it out of source control and support requests.
3. On the Pi, using Raspberry Pi Connect remote shell, SSH or a local terminal, download `install-lancerlogin.sh` and `install-lancerlogin.sh.sha256` from this release into the same folder and run `sha256sum -c install-lancerlogin.sh.sha256`.
4. Run `bash install-lancerlogin.sh --dry-run` and review the preview, then run `sudo bash install-lancerlogin.sh --install`. Pairing, fingerprint mappings and queued scans are preserved.
5. On the **Kiosks** page, confirm the kiosk is online and reports `2.0.0-beta.9`.

If the installer stops, keep the checkpoint and do not re-pair or restore an old queue. See [local recovery](../LOCAL-RECOVERY.md#recover-a-physical-kiosk-or-update).
