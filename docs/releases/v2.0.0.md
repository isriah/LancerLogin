# LancerLogin v2.0.0

LancerLogin 2 is now the stable release. It turns LancerLogin into a set of modules around built-in Attendance, supports any number of kiosks with their own sign-in methods, and makes a new installation much easier to set up. New installations from the template install this release. LancerLogin 1 installations update in place through the v1.2.6 bridge; see [Upgrade from LancerLogin 1](https://isriah.github.io/LancerLogin/updates.html#from-v1).

This release has the same application code as v2.0.0-beta.18. Installations on the Beta track that already run v2.0.0-beta.18 can update to it for the stable version number, but nothing else changes.

## Bugs fixed

- No application changes since v2.0.0-beta.18.

## Features added

- LancerLogin 2 is available on the Stable update track. It brings optional modules (Attendance built in, Outreach Participation as an official plugin, and Carpool and Guest Visits as optional plugins), multiple kiosks with fingerprint, RFID, NFC, member ID or QR sign-in, Stable and Beta update tracks, and kiosk updates that roll back automatically if the new release fails to start.
- New installations start with red and gold organization colors, and first-time setup ends on an **Attendance is ready** screen with next steps.
- The [documentation site](https://isriah.github.io/LancerLogin/) is rewritten for LancerLogin 2, with First sign-in, Update and Troubleshoot pages and screenshots taken from a real installation and the current dashboard.

## Features removed

- None since v2.0.0-beta.18.
