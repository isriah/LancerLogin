# LancerLogin v2.0.1-beta.1

Deactivated members no longer accumulate absences during inactive periods, even after they are reactivated.

## Bugs fixed

- Meetings that start while a member is inactive stay excluded from attendance rates, weekly targets, reports, CSV exports and absence notices after reactivation.
- Individual changes, bulk changes and roster imports retain each inactive period. Roster and entire-installation backups preserve that history.

Inactivity is recorded from this update onward. Members who are already inactive are tracked from the update time. Earlier inactive periods cannot be reconstructed automatically.

## Features added

None.

## Features removed

None.
