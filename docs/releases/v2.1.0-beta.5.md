# LancerLogin v2.1.0-beta.5

This beta tells Admins when a module's update did not finish. If a module's new database changes are refused, for example because the update skips a release it requires, or fail, **Settings > Modules** now marks that module and explains why in plain English. Until then this went unnoticed while the module's new code ran against its older database tables, so some of its pages could fail without explanation.

## Bugs fixed

None.

## Features added

- **Update not finished.** On the Modules card in **Settings > Modules**, a module whose update did not finish shows an **Update not finished** warning beside its name. Its row explains the reason, such as which earlier release to install first, with when LancerLogin last tried and, after repeated attempts, since when it has been failing. LancerLogin keeps trying automatically, and the warning clears once the update finishes. Only Admins see it.

## Features removed

None.

## Updating

Updating adds a small table automatically to record unfinished module updates. No action is needed.
